# 変更履歴

## v1.1.0

**版番号を直しました。** 1.0.18・1.0.19 として進めていた内容は「機能の追加」と「UI の改善」で、
パッチ（1.0.x）ではなく **MINOR（1.1.0）** が妥当です。公開前なので 2 版ぶんを 1 つにまとめ、
`package.json` / `package-lock.json` / README / 文書 / タグを 1.1.0 に揃えました。
（1.0.18・1.0.19 は配布 ZIP を作っただけの作業版番号で、公開はしていません。）

総合診断 v1.0.17（N1〜N22・S11）と v1.0.18（A1〜A3・B1〜B7・C3）、v1.0.19 の任意提案（P1〜P4・P6）を
すべて反映しています。**変換エンジン（`src/core/lang`・`src/core/sb3`）のロジックには触れていません**
（往復変換のコメント保持は、これまでどおり文書化した持ち越しです）。

### この版で入ったこと（まとめ）

**作業が消えない**
- サンプル／「新規」で置き換える前に**確認**を出し、直後なら**1 段だけ「元に戻す」**が使えます。
  何も失わないとき（コードが空で読み込み直後）は確認を出しません。
- 端末の下書きを**消せる**ようにしました（右パネルの「端末の下書きを削除」→ **件数を出してから**確認）。
  画面のコードは消しません。

**食い違いを見せない**
- ブロックの未反映は「ブロック（未反映）」バッジで示し、コードに戻るとき**自動で反映**。失敗時だけ確認して巻き戻します。
- 50 MB 超の `.sb3` ドロップ、整形の失敗、書き出しの失敗は**理由をログに残します**（無言で終わらない）。
- 空のコードでは診断が「**まだコードがありません**」と伝えます。

**キーボードと読み上げ**
- エディタの Tab は `Esc` で解除（`Ctrl/⌘+M` は**画面のどこでも**切替、設定は端末に保存）。
- 検査タブは `tablist`／矢印・Home・End、診断行は `<button>`（Enter で該当行へ）。
- `Ctrl/⌘+S` で `.sb3` を書き出し。状態変化（診断件数・未反映・保存・削除）は
  1 つの `role="status" aria-live="polite"` で通知（保存は 30 秒に 1 回まで）。

**読みやすさ**
- 夜モードの非選択ラベルを配色別に修正（明るい配色しか測っていなかった検査を **6 配色**に拡張）。
- フォーカスは内側＋外側の 2 重リング。文字の下限は **11 px**。
- ステージは **4:3** を保ったまま拡縮。Education は `h1` から始まる正しい見出し順。

**狭い画面**
- 375 px のツールバーは **297 → 109 px**、320 px は **346 → 155 px**（640 px 未満はアイコン表示、`aria-label`/`title` は保持）。
- 「端末の下書きを削除」は 320〜420 px でも**全部見えて押せる**（520 px 未満は「下書きを削除」）。
- 「コード／ブロック」は常に 1 行。4 版 × 7 幅（320〜1440）の **28 通りすべて横スクロール 0**。

**公開まわり（新規）**
- `npm run deploy` / `deploy:preview`（wrangler）、`npm run check:deploy -- <URL>`（配信物の実検査）、
  `.github/workflows/deploy-pages.yml`（push でテスト→ビルド→配信→検査）、
  `docs/07-deploy-cloudflare.md`（手順書）を追加しました。

#### v1.0.18 相当（総合診断 v1.0.17）

### 作業が消えない（N1・S11）
- **サンプルを選ぶと、確認も取り消しもなく編集内容が消えていた**。置き換える前に確認を出し、置き換えた直後に「元に戻す」（1 段）を出すようにしました。「新規」も同じ扱いです。

## v1.0.17

総合診断（v1.0.16）の指摘 V1〜V13 をすべて閉じ、**診断が挙げていない同種の穴も自力で塞ぎました**。変換エンジン（`src/core/lang`・`src/core/sb3` のロジック）には触れていません（往復変換のコメント消失＝V10 は、明言どおり持ち越しです）。

前回は「直したのに直っていない」1 件（V2/V3）を含んでいました。今回は**直したと書いた項目すべてに、実際に壊れる／切れる入力をテストとして固定**しています。

### 配信ヘッダ（V1・V4・V13）
- **教育版の `index.html` 直 URL に CSP が無かった**（v1.0.15 からの回帰）。文書ブロックを「6 パス列挙」から**版のディレクトリ単位**（`/`・`/index.html`・`/en/*`・`/education/*`）に変更しました。パスを 1 本ずつ書く方式そのものが「書き忘れた文書だけ無防備」を生むため、列挙をやめています。
- `scripts/check-headers.mjs` を**`dist/**/index.html` から URL を導出**する方式に全面書き換え。ハードコードしたパスは 1 つもありません。検査対象は 16 文書パス、すべて `frame-ancestors 'none'`／`X-Frame-Options: DENY`、runner は `'self'`／`SAMEORIGIN`、重複 0、適用順に依存しないことを実測で確認しています。
- **版の一覧を `scripts/lib/editions.mjs` に集約**しました。`scripts/build-pages.mjs`・CI・テストはすべてここから導出するため、版を足したときの更新漏れが構造的に起きません（新規 `npm run check:editions`。CI にあった `for f in dist/...` の書き写しも削除）。
- 各版に複製されていた `_headers`（3 コピー）をビルド時に削除。配信物に残るのは出力ルートの `dist/_headers` だけです。

### Education の残置物（V5・V6）
- Education ビルドで `theme-init.js` を出力しないようにしました（`dist/theme-init.js` と `dist/en/theme-init.js` のみが残ります）。
- 「配色を最初の描画前に決める」という**削除済みの処理を説明するコメント**を Education の HTML から除去（Vite の transform で削除＋`closeBundle` で成果物の残留も削除）。

### AI サニタイザ（V2・V3）と、診断が挙げていない同種の不具合
- **入れ子リスト・散文の誤検知を解消**。原因は 2 つありました。(1) 箇条書き記号を外した後に命令語判定をしていたため「- say の使い方」がコード扱い、(2) 4 スペース以上のインデント塊を無条件にコード扱い。(1) は**日本語を含む行を説明文とみなす**判定を先に行い、(2) は**インデント量を判定材料から完全に削除**しました（判定は代入・構文・呼び出し・命令語＋`(` や引用符という形だけ）。
- 実測（修正後）: 4 スペースの入れ子リスト 13／20／40 行 → すべて通過（20→20、40→40）。2 スペースも同様。4 スペースの散文 20 行 → 通過。`- say の使い方` × 15 → 通過。URL 30 行 → 通過。コードは 12 行まで通過し、**13 行目から**案内文に置換（`say(...)`・`    move(10)`・`> say(...)`・`1. say(...)`・`- say(...)` のすべてで同じ境界）。
- **診断未記載の不具合**: 連続 12 行の上限と全体 24 行の予算が同時に効くと、案内文が**2 回並んで**いました。連続する同一行を 1 つに畳んでいます（60 行のコードで案内文 1 回を実測）。
- `release-v116.test.ts` の「keeps nested bullet lists」は、**実際には切られない入力（1 行おきの字下げ）しか試していませんでした**（V3）。「12 行は通過／13 行は遮断」の境界、40 行の入れ子リスト、案内文が 1 回だけであることを固定するテストに差し替えました。

### AI 返答の描画（V7）
- 番号付きリストを `<ol>`、引用を `<blockquote>`（`>` は表示しない）、フェンスを `<pre><code>`、`\*` などのバックスラッシュエスケープを処理。**空文字列は空配列**を返します（以前は `<br/>` 1 個）。表は記号を消さず読みやすい文字列のまま出します。
- HTML 文字列を組み立てない設計（`dangerouslySetInnerHTML` 不使用）は維持。`<script>` は要素化されず文字列として出ることをテストで固定。

### CSS（V8）と、診断が挙げていない同種の不具合
- `var(--code-bg, …)` / `var(--ink, …)` / `var(--warn-soft, …)` という**どこにも定義の無い変数**を廃止し、`--code-inline-bg` / `--code-inline-ink` / `--note-bg` / `--note-ink` を**ライトとダークの両方**で定義しました（コントラスト実測: 13.78 / 6.99 / ダーク 11.0 / 10.22）。
- **診断未記載の不具合**: `styles.css` に `:root` と `html[data-theme="dark"]` がそれぞれ 2 回現れ、後のブロックが前のブロックの 18 個を黙って上書きしていました（`--editor-bg` は同一ブロック内で 2 回）。テーマ変数をファイル冒頭の 1 か所に統合し、**統合前後の実効値を機械的に比較して完全一致を確認**しています。`.guide-page` の二重定義も同様に統合しました。
- **新規 `npm run check:cssvars`**: `var(--x)` に定義があるか、同じテーマ用セレクタで同じ変数を 2 回定義していないか、同一ブロック内で重複していないかを静的に検査します（ビルド不要・CI 実行）。わざと未定義変数を混ぜると `--not-defined` / `--ink` を検出して失敗することを確認済みです。

### アクセシビリティ（V9）
- `LearnGuide` の `useEffect` 依存から `onClose` を外し、**マウント時の 1 回だけ**実行するようにしました（最新の関数は ref で保持）。ガイド表示中に親が再レンダーしても、`inert`／`aria-hidden` の付け直しとフォーカス復帰が走りません。

### `postMessage` の `'*'`（V11・方針を決定）
- 実行 iframe は `sandbox="allow-scripts"`（`allow-same-origin` なし）＝**不透明オリジン**なので、`targetOrigin` は仕様上 `'*'` 以外を指定できません（`'null'` を渡しても届かない）。したがって「具体的なオリジンに変える」ことはできません。
- 代わりに `src/app/components/runnerBridge.ts` へ送信を集約し、(1) 送信先は親が保持する自前 iframe の `contentWindow` のみ、(2) payload は許可したキーだけを**明示的に組み立てる**（オブジェクトのスプレッドを使わない）ことを構造的に保証しました。将来 payload に API キーが紛れ込んでも外に出ません（余計なキーが落ちることをテストで固定）。sandbox 属性も定数化して固定しています。
- 受信側（runner）は従来どおり `document.referrer` から求めた親オリジンを検査し、親側も `event.source` と `event.origin === 'null'` を検査します。

- `.sb3` 取り込みに上限：圧縮後 50 MB / 2,000 エントリ / 展開後 300 MB。`fflate` の `filter` で展開しながら打ち切り、`zip.tooLarge` / `zip.tooManyEntries` / `zip.expandsTooMuch` を日英表示。ファイルサイズは読み込み前に検査。
- テキスト入力に上限：50,000 行 / 2 MB（`text.tooLarge`）。同期パースで UI を固めません。
- 取り込み経路の想定外例外を最上位で `Sb3ParseError` に包み、内部 `TypeError` の文言を画面に出さない。
- `saveSb3` は `Object.create(null)` に加えてアセット名を検証し、`__proto__` 等は書き出さない。
- `public/_headers` を全面整備：CSP（`default-src 'self'`・`frame-ancestors 'none'`・`object-src 'none'`・`base-uri 'none'`・`connect-src` は3社APIのみ）、`X-Frame-Options: DENY`、`Cross-Origin-Opener-Policy`、`Permissions-Policy`（カメラ・マイク・位置情報ほか全否認）。`/scratch-runner/*` は `frame-ancestors 'self'` と meta CSP に揃えた内容。
- 実行サンドボックスは `document.referrer` から親オリジンを推定して検証し、`postMessage` の送信先も親オリジンに限定（第三者ページからの駆動を拒否）。
- 開発・プレビューサーバの `allowedHosts: true` を廃止し、`localhost` / `127.0.0.1` / `[::1]` と `PREVIEW_HOST` のみ許可。
- 座標の無いスプライトは `x/y = 0` として取り込み（`undefined` をコードに書かない）。
- CI を commit SHA 固定、`npm ci --ignore-scripts`、`tsc --noEmit`、`npm test`、`npm audit --omit=dev`、4版ビルド＋成果物確認に強化。Dependabot（npm 週次・Actions 月次）を追加。
- `collectUi()` は引数なしでも allowlist を読むようにし、除外分が `frozen` に混ざらないようにしました（`skipFiles` も返す）。
- Education 版の localStorage（進捗・下書き）に関する共有端末の注意を README に追記。
