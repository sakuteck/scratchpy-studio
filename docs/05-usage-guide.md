# ScratchPy Studio 使い方ガイド

> **はじめに知っておくこと**
> - **サンプルや「新規」を選ぶと、いま編集中のコードは置き換わります**（確認が出て、直後なら 1 回だけ「元に戻す」が使えます）。
> - **ブロックの編集は「コードに反映」を押すまでコード・実行・保存に反映されません**（未反映のあいだは「ブロック（未反映）」と表示されます）。
> - コードは**この端末（ブラウザ）にだけ**自動保存されます。サーバーには送られません。
> - Education 版は**子どもの視線と読みやすさを優先して配色を固定**しています（OS のダーク設定には追従しません）。

---

## 1. これは何をするツール?

**ScratchPy Studio** は、Scratch のプロジェクトファイル(**.sb3**)と、
Python 風のテキスト言語 **ScratchPy**(スクラッチパイ)を**双方向に変換**する Web ツールです。

```
 .sb3(Scratch)  ──変換──▶  ScratchPy テキスト  ──変換──▶  .sb3(Scratch)
     「開く」                   編集・診断・整形                 「ダウンロード」
```

できること:

- Scratch の .sb3 を読み込んで、ScratchPy のコードとして表示・編集
- ScratchPy のコードを .sb3 としてダウンロード(Scratch / TurboWarp でそのまま開けます)
- 入力しながら**日本語のエラー・警告**をリアルタイム表示(型チェック付き)
- プログラムの構造ツリー、生成される project.json のプレビュー
- ワンクリック整形、サンプルプログラム 4 本を内蔵

変換と診断は**ブラウザ内**で行われます。AIチューターを使用するときだけ、確認・同意後に質問、コードの先頭12,000文字、会話、診断と言語仕様が選択したAI事業者に送信されます。AIは説明専用で、コードの生成・修正・適用は行いません。画像・音声のファイル自体は送信しません。

| 領域 | 説明 |
|---|---|
| ツールバー | 変換・ファイル操作ボタン、サンプル選択、使い方・説明、**カラーモード**のプルダウン |
| エディタ | **コード / ブロック** の 2 モード切替。コードは行番号付き、Tab で 4 スペースインデント |

### カラーモード（配色のプルダウン）

ツールバー右の **配色** プルダウンから、6 種類のカラーモードを選べます。選択は `localStorage`（キー `sp-color-mode`）に保存され、次に開いたときも同じ配色になります。

| メニュー表示 | 印象 | 用途 |
|---|---|---|
| **通常** | 落ち着いた濃紺のツールバー＋白いエディタ | 既定の標準配色。Scratch の隣に置いても落ち着く |
| **Scratch** | Scratch のカテゴリ色に近い青 | Scratch と並べて使うとき |
| **パステル** | 淡い紫 | 長時間の閲覧で目が疲れにくい |
| **高コントラスト** | 白地・黒文字・黒ツールバー | 視認性を最優先するとき |
| **夜** | 濃い背景＋明るい文字 | 暗い部屋 |
| **夜・高コントラスト** | 純黒背景＋白枠 | 夜間の視認性を最優先するとき |

すべてのモードで、**画面上に見えているテキスト**（本文・ボタン・タブ・構造ツリー・バッジ・診断アイコン・エディタの行番号）が **WCAG AA（4.5:1）以上**になることを、実ブラウザ計測（`npm run check:contrast`：4 版 × 主要画面、レッスン内のクイズ・ヒント・答え合わせも含む）と 6 モードの計測（`npm run check:colours`）で確認しています（どちらもリポジトリ内のスクリプトで、CI でも実行されます）。フォーカスリングなどの**非テキスト**は 3:1 を基準にし、明るい配色では濃いアンバー（`#b45309`）に切り替えます。
計測は実際に描画された色を親要素の背景まで合成して行います（半透明レイヤーを含む）。CSS 側は `npm run check:cssvars` が「`var(--x)` に定義があるか」「同じテーマ用セレクタで同じ変数を 2 回定義していないか」を静的に検査します（v1.0.17 で追加。以前は存在しない変数にフォールバックで気づけない状態でした）。版と成果物の対応は `npm run check:editions`、配信ヘッダの網羅性は `npm run check:headers` が確認します。グラデーションの中間色は厳密には含みません（両端は計測済み）。Education 版の 21 規則も v1.0.15〜v1.0.16 で AA 以上に調整しました。

## 3. クイックスタート(3 分)

1. **ツールを開く**と、サンプル「こんにちは ScratchPy!」が表示されています。
2. 右の **診断** タブを確認 → 「エラー・警告はありません」と出ていれば OK。
3. **.sb3 をダウンロード** をクリック → `project.sb3` が保存されます。
4. [Scratch エディタ](https://scratch.mit.edu/projects/editor/) で
   「ファイル → コンピューターから読み込む」(または [TurboWarp](https://turbowarp.org/) にドロップ)→ 動きます!
5. エディタのコードをいじって(例: `"こんにちは!"` を `"やあ!"` に)、もう一度ダウンロードしてみましょう。

## 3.5 Blockly ブロックエディタ

「ブロック」タブを開くと、現在のコードを Blockly のワークスペースで編集できます。

1. 左のカテゴリからブロックをドラッグし、ステージまたはスプライト内の適切な位置につなぎます。
2. 数値や文字をクリックすると入力できます。ホイールやツールバーで拡大・縮小できます。
3. 編集が終わったら **「コードに反映」** を押します。コード表示に切り替え、診断タブでエラーを確認できます。
4. 「再読み込み」は現在のコードからブロックを作り直します。未反映の編集がある場合は確認が出ます。

未接続ブロックや複数のステージがあると反映できません。構文エラーがあるコードや、Blockly で完全に保持できない構文を含むコードは、元のコードを守るため反映が無効になります。コードを直接編集してください。反映は自動ではなく明示的に行います。コードとブロックの両方を別々に編集した場合、ブロックを上書き適用することはできません。

カスタムブロックの呼び出しは、定義をコードへ反映したあと、再読み込みすると「マイブロック」に現れます。

## 3.6 AIチューター（通常版・説明専用）

右の「AIチューター」は、**わからない部分を教えてもらう**ためのパネルです。作品を作ってもらう機能はありません。Gemini、OpenAI、Anthropic を選び、APIキーとモデルIDを入力し、「API設定」で同意してから「質問に戻る」を押します。Gemini 2.5 Flashに限り、任意の高推論モードで思考予算と応答上限を増やせます（時間・料金が増える可能性があり、性能向上は保証できません）。

- 送られるもの：質問文、コードの先頭 12,000 文字、ローカル診断、直近4往復の会話。入力欄の下に常時表示されます。
- できること：用語・文法・型の説明、診断メッセージの意味と直し方、行番号を挙げた解説、12行以内の短い例示、確認質問。
- できないこと：作品全体の生成、修正済みファイルの出力、エディターへの適用、自動修正、Scratch の実行。長いコード塊や完成品らしいフェンスは表示されません。
- 通信は1質問につき1回（Gemini の HTTP 503 のときだけ最大2回再送）。エラー文言からはAPIキーを伏せ、キーがコードや質問に含まれる場合は送信を中止します。
- キーはブラウザのメモリーにのみ保持されますが、ブラウザ拡張や端末の利用者に見える可能性があります。共有端末での使用は避け、キーに権限・利用上限を設定してください。ブラウザ接続は事業者のCORS・組織設定により拒否される場合があります。

AIの説明は間違えることがあります。**エディターの診断とScratchでの動作を正**としてください。

## 4. .sb3 を ScratchPy に変換する

方法は 2 つ:

- **.sb3 を開く** ボタン → ファイル選択
- **.sb3 ファイルをウィンドウにドラッグ&ドロップ**(画面が青くなったら離す)

変換されると:

- エディタに ScratchPy コードが表示されます
- ステータスバーに読み込んだファイル名が出ます
- **ログ** タブに変換の詳細(スプライト数・ブロック数・変換メモ)が記録されます

### 変換メモ(notes)の読み方

ログに次のようなメモが出ることがあります。**エラーではありません**:

| メモ | 意味 |
|---|---|
| `未対応ブロック: xxx → コメント行に変換されました` | ScratchPy に対応する書き方がないブロック(TurboWarp 拡張など)。コード内には `# [変換不可ブロック]` コメントとして残りますが、**もう一度 .sb3 に変換するとこの部分は失われます** |
| `ハットブロックなしの孤立したスクリプトはコメント化しました` | Scratch 上で「実行されないブロック」だったもの。コメントとして全文残ります |
| `値モニターは変換対象外のため無視しました` | タイマー表示などのモニター。変数・リストのモニターは変換されます |

### 元に戻したいとき

読み込んだ .sb3 の**画像・音はそのまま保持**されます。コードを編集して
「ダウンロード」すれば、元のアセットを使った .sb3 が生成されます
(コスチューム名・音名を変えなければバイト単位で同一です)。

## 5. ScratchPy の書き方(ミニチュートリアル)

詳しい仕様は `docs/01-scratchpy-language.md` へ。ここでは最短コースで:

### ① スプライトとイベント

```scratchpy
sprite Cat:
    costume costume1

    on flag:            # 緑の旗が押されたとき
        say("こんにちは!")
```

### ② 変数(型を書く!)

```scratchpy
stage:
    var score: int = 0 @show      # 画面に表示される整数変数

sprite Cat:
    on flag:
        score = 0
        score += 10               # score は int なので += できる
```

型が違うと**その場で赤いエラー**になります:

```scratchpy
var score: int = "りんご"   # ✗ エラー: int 型に str は代入できません
```

### ③ くり返しと条件

```scratchpy
on flag:
    repeat 10:
        move(10)
        if touching("edge"):
            bounce()
    while score < 100:
        score += 1
```

### ④ カスタムブロック(関数)

```scratchpy
sprite Cat:
    def jump(power: int):
        repeat power:
            change_y(10)

    on flag:
        jump(5)
```

### ⑤ リスト

```scratchpy
stage:
    list "取った果物": list[str] = [] @show

sprite Apple:
    on click:
        "取った果物".add("リンゴ")
        say(len("取った果物"))
```

## 6. タブパネルの使い方

### 診断

- エラー(!)/ 警告(▲)が一覧表示されます。**クリックすると該当行へジャンプ**します。
- エラーが 1 つでもあると ダウンロードボタンは無効になります(グレー表示)。
- 警告は変換自体はできます(例:「結果が使われていません」)。

### 構造

プログラムを木で表示します:

```
▼ ステージ  Stage          2 スクリプト
    変数  score: int       = 0 / 表示ON
    リスト  items: list[str]  3 要素
  ▼ スプライト  Cat         1 スクリプト
    ▼ イベント  on flag:    3 文
        move(10)
        ...
```

▶/▼ で折りたたみ・展開。「どのスプライトに何があるか」の把握に使えます。

### { } JSON

現在のコードから生成される **project.json(Scratch の内部形式)のプレビュー**です。
エラーがあると生成されません。.sb3 の中身を勉強したいときにどうぞ(→ `docs/02-sb3-format-analysis.md`)。

### ログ

変換・読み込み・ダウンロードの履歴。
.sb3 読み込み時の変換メモ(notes)や未対応ブロックの一覧もここに出ます。

## 7. よくある質問(FAQ)

**Q. ダウンロードした .sb3 が Scratch で開けません**
A. このツールは生成時に構造検証を行っています。それでも開けない場合は、
ログの検証警告を確認し、プロジェクト名を変えて保存し直してみてください。
(TurboWarp ではより寛容に読み込めます)

**Q. コメントは .sb3 に保存されますか?**
A. いいえ。ScratchPy のコメントは .sb3 往復で失われます。
逆に、.sb3 側の「吹き出しコメント」もテキストには取り込まれません。

**Q. 変換したらブロックが減りました**
A. ログを見てください。未対応ブロック(TurboWarp 拡張・「値を返すカスタムブロック」など)は
コメント行に変換され、再変換時に失われます。対応済み: 動き・見た目・音・イベント・制御・
センシング・演算・変数・リスト・マイブロック・ペン拡張。

**Q. 変数に型を付けたくないのですが…**
A. `var x: any = 0` とすると型チェックを緩められます。
また .sb3 から変換したときに型が衝突する変数は自動的に `any` になります。

**Q. クラウド変数は?**
A. `stage:` 内で `var "☁ 名前": int = 0 @cloud @show` のように書きます。数値型のみです。

**Q. 日本語の変数名は使えますか?**
A. はい。`var 点数: int = 0` のようにそのまま書けます。
空白や記号を含む名前は `var "my var": int = 0` のように引用符で囲みます。

**Q. ファイルはどこかに送信されますか?**
A. 通常の変換はブラウザ内で行われます。AIチューターを使う場合、同意のうえ質問・コードの先頭12,000文字・会話・診断・言語仕様が選択した事業者へ送られます。AIは説明だけを行い、コードは変更しません。APIキーはページのメモリーのみで保持し、アプリは保存しません。

## 8. キーボード操作

| キー | 動作 |
|---|---|
| Tab | カーソル位置に 4 スペース挿入 |
| Shift + Tab | 行頭のインデントを削除 |
| Esc → Tab | エディタから抜けて、次のボタンへ移動（エディタ右上に「Tab 移動モード」と表示） |
| Ctrl/⌘ + M | Tab の動き（挿入／移動）を切り替え（画面のどこでも／設定はこの端末に保存） |
| Ctrl/⌘ + S | `.sb3` を書き出す（ブラウザの「ページを保存」は開きません） |
| ← → / Home / End | 右のタブ（AI・診断・構造・JSON・ログ）を移動 |
| (診断行で Enter) | 該当行へジャンプして行を選択 |

> **Esc の使いどころ**：Tab は通常「インデント」なので、キーボードだけで画面を移動したいときは
> 一度 Esc を押します。案内が消えるのは「Tab 移動モード」の間だけです。

## 9. 下書き・取り消し・サンプルの読み込み

- コードは**この端末（ブラウザの IndexedDB）にだけ**自動保存されます。サーバーには送られません。
- サンプルや「新規」でコードを置き換えるときは**確認**が出ます。置き換えた直後は画面上部に
  **「元に戻す」**が出るので、1 回だけ前の状態に戻せます。
- 共有端末で使ったあとは、右パネル上部の **「端末の下書きを削除」**（狭い画面では「下書きを削除」）で、
  保存した下書き（コード・読み込んだ画像と音）を消せます。**消す前に件数が出ます**。画面のコードはそのまま残ります。
- 狭い画面では、ツールバーのボタンが**アイコンだけ**になります（読み上げ名と `title` は残ります）。
- ブロックで編集した内容は「コードに反映」を押すまでコードに届きません。未反映のときは
  「ブロック（未反映）」と表示され、ブロックからコードへ切り替えるときに自動で反映を試みます。

### GeminiでHTTP 503が出たら

モデルの一時的な混雑・停止が原因の場合があります。最大2回自動で再試行し、待機中は中止できます。それでも失敗したら少し待って再送するか、設定で利用可能な別のモデルIDを試してください。APIキーの変更は通常不要です。ブラウザのコンソールには失敗したリクエストの503が残る場合があります。再送は追加の通信や料金につながる場合があります。StudioのAIチューターは1質問につき1リクエストで、再送が発生しても最大3回です（自動修正のループはありません）。
